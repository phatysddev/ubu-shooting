# RED EARTH

ต้นแบบเกม FPS ออนไลน์บนเว็บด้วย Three.js และ Node/WebSocket ฉากสะวันนาแอฟริกาสมมติ สำหรับคอมพิวเตอร์ เมาส์และคีย์บอร์ด โมเดลและเสียงสร้างด้วยโค้ด ยังไม่ใช่งาน photorealistic ระดับ AAA

## เปิดเล่น

ใช้ Node.js 22 ขึ้นไป รัน `npm install` แล้ว `npm run dev` เปิด http://localhost:3000 ใส่ชื่อและรหัสห้อง ผู้เล่นในเซิร์ฟเวอร์และห้องเดียวกันเจอกันได้ สูงสุด 8 คน หากอยู่คนเดียวมีเป้าฝึกยิง (ไม่ให้คิลหรือแต้มอัลติ)

## ปุ่มควบคุม

- WASD เดิน / ขับรถ, Shift วิ่ง / เร่งรถ, Space กระโดด, C ย่อ
- คลิกซ้ายยิง, คลิกขวาค้างหรือ Z เปิด–ปิดการเล็ง, R รีโหลด
- 1 / 2 ปืนหลัก / รอง, 3 หรือ V มีด, สกอลล์เมาส์วนสามช่อง
- G ขว้างระเบิด 2 ลูกต่อชีวิต
- Q / E ใช้สกิลสองช่องที่เลือกก่อนเข้าเกม
- T อัลติเมื่อสะสมคิลผู้เล่นครบ 5 คน
- B สุ่มสกิลปืนกระบอกที่ถืออยู่ (คูลดาวน์ 8 วินาที)
- H ขึ้น / ลงรถที่อยู่ใกล้ (คนขับหนึ่งคนต่อคัน ยิงระหว่างขับได้)
- Tab คะแนน, Esc พัก, ไอคอนตั้งค่าปรับความไวเมาส์และ ADS แยกกัน

เบราว์เซอร์ที่ไม่รองรับ pointer lock ใช้คลิกขวาค้างแล้วลากเพื่อมองแทน มีดเล็งและซูมไม่ได้ สโคปมีมุมมองกว้างขึ้น ศูนย์ไม่ไหลขึ้นจากการยิง และลดแรงถีบ/การโยกขณะ ADS

## ชุดอุปกรณ์และสกิล

เลือกปืนหลัก–รองจากปืน 12 แบบ มีไรเฟิล SMG ลูกซอง สไนเปอร์ DMR LMG ปืนพกและ RPG พร้อมมีดติดตัว กระสุนแต่ละกระบอกแยกกัน รีโหลดมีแอนิเมชันถอด–ใส่แม็ก ป้อนลูกซอง หรือใส่หัวจรวด กระสุนเติมเมื่อเซิร์ฟเวอร์รีโหลดเสร็จเท่านั้น สลับปืนยกเลิกการรีโหลด

เลือกสกิลได้ **2 อย่างเท่านั้น** จาก dash, smoke, heal, ice wall แล้วใช้ Q/E ตามช่อง เซิร์ฟเวอร์ปฏิเสธสกิลที่ไม่ได้เลือก:

- Dash: พุ่ง 7 หน่วย คูลดาวน์ 12s กันเดินทะลุกำแพง
- Smoke: ระยะวางสูงสุด 11 หน่วย รัศมี 5 อยู่นาน 8s คูลดาวน์ 18s บดบังภาพและชื่อ แต่ยิงทะลุได้
- Heal: 12 HP/s นาน 3s คูลดาวน์ 25s หยุดเมื่อถูกทำร้าย กดตอนเต็มไม่เสียคูลดาวน์
- Ice wall: 450 HP, อยู่ 20s, คูลดาวน์ 4s กันเดิน/กระสุน/แรงระเบิด ยิงทำลายได้ วางทับผู้เล่น อาคารหรือกำแพงอื่นไม่ได้

## สกิลปืนแบบสุ่ม

ปืนหลักและรองได้รับสกิลแยกกันเมื่อเกิดใหม่ กด B สุ่มใหม่โดยไม่ซ้ำสกิลเดิม มี OVERPOWER (+50% damage), RAPID FIRE (ระยะห่างนัด ×0.65), LIFE STEAL (ดูดเลือด 25%), QUICK LOAD (เวลารีโหลด ×0.6), FROST BITE (ศัตรูช้าลง 2s), BLAST ROUND (กระสุนโดนตัวแล้วระเบิดวงเล็ก) มีดสุ่มไม่ได้ ไม่ใช้เงินจริง

RPG มี 3 นัด ยิงทุก 400ms รีโหลด 1.8s ดาเมจสูงสุด 420 รัศมี 14 หน่วย จรวดเร็ว 70 หน่วย/s และติดตามศัตรูด้านหน้าที่มองเห็นได้ในระยะ 200 หน่วย ไม่หักโค้งทะลุกำแพง Self-splash เหลือ 20% แต่ยังทำร้ายตัวเองได้

## รถ

รถจี๊ป 4 คันต่อห้อง 600 HP ขับได้คนเดียว ใช้ WASD ขับเลี้ยว เมาส์มองและยิง การกด H ลงรถจะหาพื้นที่ว่าง รถเกิดใหม่ 15s หลังถูกทำลาย ผู้ขับถูกบังคับออกและได้รับความเสียหาย 60 เมื่อรถพัง ลงรถก่อนใช้สกิล Q/E ไม่ใช่ระบบรถหลายที่นั่งหรือฟิสิกส์รถเต็มรูปแบบ

## ตัวละครและอัลติ

NOVA, SABLE, VALKYRIE เป็นตัวละครผู้ใหญ่ 28–30 ปี มี RANGER และ BASTION เกราะหนักด้วย BASTION มี 175 HP และความเร็ว 78% ตัวอื่นมี 100 HP

ฆ่าผู้เล่นจริงครบ 5 คน กด T ใช้อัลติ 15s แต้มคิลเก็บข้ามชีวิตจนกว่าจะใช้ อัลติที่กำลังทำงานจบเมื่อตาย:

- NOVA / OVERDRIVE: ระยะห่างนัด ×0.25, ความเร็ว ×1.6, ดาเมจ ×3
- SABLE / DEAD EYE: ดาเมจ ×8, ลดแรงถีบมาก, เปิดชื่อศัตรูทั่วแมพ (ชื่อยังถูก geometry บังตาม depth test)
- VALKYRIE / WORLD BREAKER: เตือน 3s ก่อนทำดาเมจมหาศาลทั่วแมพ ยกเว้นผู้ใช้ ทำลายไอซ์วอลล์และเป้าฝึก
- RANGER / ORBITAL JUDGMENT: เตือน 3s ก่อนยิง orbital blast ทุกตำแหน่งศัตรู ฟื้นเลือดเต็มและดาเมจ ×4 อาจโดน blast ของตัวเองหากอยู่ใกล้ศัตรู
- BASTION / IRON FORTRESS: ฟื้นเลือดเต็ม รับดาเมจเหลือ 5% และปล่อย shock damage ทั่วแมพหลัง 3s

เกมเป็น free-for-all ไม่มีทีม บัฟและอัลติตั้งใจแรงตามคำขอผู้ใช้ ไม่มี economy หรือบัญชีผู้ใช้

## ตรวจสอบ / deploy

เปิดเซิร์ฟเวอร์ก่อน `npm test` และใช้ `npm run build` สร้างไฟล์จริง ตั้ง `NODE_ENV=production` แล้ว `npm start` รองรับ `PORT` มี Dockerfile และ render.yaml สำหรับโฮสต์ที่รองรับ WebSocket

ต้อง deploy ทั้ง Node server และ dist; static hosting อย่างเดียวใช้ multiplayer ไม่ได้ ใช้ instance เดียว ห้อง คะแนน รถและสิ่งชั่วคราวอยู่ในหน่วยความจำ รีสตาร์ตแล้วล้างหมด รหัสห้องไม่ใช่รหัสผ่าน ยังไม่ได้เผยแพร่บน URL สาธารณะ ถ้าจะส่งลิงก์ให้เพื่อนต่างเครื่อง ต้องใช้ IP หรือโฮสต์ที่เพื่อนเข้าถึงได้ ไม่ใช่ localhost

ฟอนต์ self-hosted จาก Fontsource (OFL) ใบอนุญาตอยู่ public/fonts; ใช้ API ของ Three.js ตาม https://threejs.org/docs/
